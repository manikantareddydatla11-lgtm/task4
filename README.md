# FAQ Accordion

## Project Overview
The FAQ Accordion is a responsive web component that allows
users to expand and collapse frequently asked questions.
It provides a simple and user-friendly way to display answers.

## Objective
To practice DOM manipulation, JavaScript event handling,
CSS class manipulation, and responsive UI development.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Features
- Eight frequently asked questions
- Expandable and collapsible answers
- Only one answer remains open at a time
- Active question styling
- Plus icon animation
- Responsive layout for mobile and desktop
- Accessible buttons and keyboard focus styles

## Project Structure
faq-accordion/
- index.html
- style.css
- script.js
- README.md

## How to Run
1. Download or clone the project repository.
2. Open the project folder in VS Code.
3. Open index.html in a browser.
4. Click any question to view its answer.
5. Click the same question again to close it.

## JavaScript Concepts Used
- querySelectorAll()
- querySelector()
- addEventListener()
- classList.toggle()
- getAttribute()
- setAttribute()
- DOM manipulation

## Learning Outcomes
- Understanding interactive UI components
- Handling click events in JavaScript
- Showing and hiding HTML elements
- Applying CSS classes dynamically
- Creating responsive web pages
